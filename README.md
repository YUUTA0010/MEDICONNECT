# MEDICONNECT

MediConnect is a modern React web app to find medicines at nearby pharmacies, compare prices, and order for delivery or pickup. It features an AI-powered symptom checker and medicine substitute finder using Google Gemini. Built with React, TypeScript, Vite, and Tailwind CSS.

View your app in AI Studio: https://ai.studio/apps/drive/1gNyZTaGx7BpAuOFkq1mZQk_qRuXhYtlm

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
